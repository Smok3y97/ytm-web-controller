Action Settings
When enabled, the song cover of the current track is displayed directly on the button.
Text Format
Placeholders: {artist}, {song}, {title}, {album}, {current}, {duration}, {remaining}, {both}.
Multi-line support: Press Enter to create new lines (Default: {artist}\n\n{song}\n\n{both}). Long text scrolls smoothly via marquee!
💡 Tip: To customize text position (Top, Middle, Bottom), font size, or text color, use the native Stream Deck "T" (Title Styler) button directly above this settings pane.
Controls
• Short Press: Toggle Play / Pause
• Long Press (Hold): Bring YouTube Music / PWA to foreground
